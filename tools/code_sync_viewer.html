Без конфликтов
  • 1. Сел за работу ➔ Забрать обновления
    git pull origin main
  • 2. Перед уходом ➔ Проверить что изменено
    git status
  • 3. Закончил сессию ➔ Запушить в ОБА облака
    git add . && git commit -m "update: прогресс" && git push origin main
