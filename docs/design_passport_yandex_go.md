## 2. Типографика

> **Шрифт Яндекс:** `YS Text` (проприетарный). **Наш маппинг для Flutter:** `Inter` (через `google_fonts`) или бандл `MontFamily`.

### 2.1 Шкала типов (Type Scale)

```
Display     34/40  Bold(700)   ls:-0.4   →  Героическая цена ("до 442₽")
Heading XL  28/34  Bold(700)   ls:-0.3   →  Заголовки страниц ("Регистрация")
Heading L   22/28  Bold(700)   ls:-0.2   →  Заголовки секций ("Выберите сервис")
Heading M   18/24  Semi(600)   ls: 0     →  Подзаголовки ("Самый быстрый")
Heading S   16/22  Semi(600)   ls: 0     →  Названия карточек ("Водитель такси")
Body L      16/22  Reg(400)    ls: 0     →  Опции в списке ("Комментарий водителю")
Body M      14/20  Reg(400)    ls: 0     →  Описания, подписи тарифов
Body S      13/18  Reg(400)    ls: 0     →  Время в чипсах ("25 мин")
Caption     12/16  Reg(400)    ls:+0.1   →  Лейблы иконок ("Доставка"), бейджи
Caption B   12/16  Semi(600)   ls:+0.1   →  Активный чип, цена в карусели
Overline    11/14  Med(500)    ls:+0.5   →  Label над полем ("Город")
Button      16/22  Semi(600)   ls: 0     →  CTA текст ("Заказать", "Готово")
```

### 2.2 Ключевые паттерны

> [!TIP]
> **Правило «600 vs 400»:** Яндекс Go использует **SemiBold (600)** только для заголовков, кнопок и акцентов. Основной текст — строго **Regular (400)**. Никакого Bold (700) в body, никакого Black (900) нигде в интерфейсе. Это создаёт ощущение воздуха и лёгкости.

- **Заголовки страниц:** Heading XL (28px, w700) — крупно, без верхнего регистра.
- **Секции внутри страницы:** Heading L (22px, w700) — достаточно крупно, чтобы визуально отделять блоки.
- **Цены:** Display (34px) для hero-цены, Body L/M (16-14px) для второстепенных цен.

## 4. Border Radius

| Токен | Значение | Применение |
|-------|---------|-----------|
| `radius.xs` | 4px | Мелкие бейджи, теги цен |
| `radius.s` | 8px | Бейдж ETA на карте, инпуты |
| `radius.m` | 12px | Контейнер иконки сервиса, чипы, карточка тарифа в карусели |
| `radius.l` | 16px | **Стандартная карточка** (тарифы, сервисы регистрации, контент-карты) |
| `radius.xl` | 20px | Промо-карточки в ленте |
| `radius.xxl` | 24px | **Верхние углы bottom sheet** |
| `radius.pill` | 100px | **CTA-кнопки**, search bar, чипы локации, бейдж ETA |

> [!NOTE]
> **Яндекс Go НИКОГДА не использует острые прямые углы (0px) на карточках.** Минимум — 8px. Bottom sheet — всегда 24px сверху. CTA — всегда pill (полностью скруглённая).

## 5. Тени (Elevation)

Яндекс Go использует **предельно сдержанные тени** — почти плоский дизайн с минимальным лифтом:

| Уровень | offsetY | blur | color | Применение |
|---------|---------|------|-------|-----------|
| `shadow.none` | — | — | — | Сетка иконок сервисов (контраст фоном, не тенью!) |
| `shadow.xs` | 1px | 4px | `rgba(0,0,0,0.04)` | Карточки тарифов в горизонтальной карусели |
| `shadow.s` | 2px | 8px | `rgba(0,0,0,0.06)` | Карточки сервисов на экране регистрации, плавающая кнопка «Назад» |
| `shadow.m` | 4px | 16px | `rgba(0,0,0,0.08)` | Bottom sheet, плавающие панели на карте |
| `shadow.l` | 8px | 24px | `rgba(0,0,0,0.10)` | Модальные окна |
| `shadow.top` | −2px | 12px | `rgba(0,0,0,0.06)` | Тень сверху от bottom nav bar |

> [!WARNING]
> **Нулевая толерантность к «тяжёлым» теням.** Если тень видна невооружённым глазом при первом взгляде — она слишком жирная. В Яндекс Go тени — это ощущение, а не графический элемент.

## 9. Чеклист внедрения

- [ ] Заменить все `Colors.black` на `#21201F` (тёплый графит)
- [ ] Заменить все `Color(0xFF6B6560)` на `#6D6B69` (точный secondary)
- [ ] Все CTA-кнопки: `height: 52`, `borderRadius: 100` (pill), текст `w600` 16px
- [ ] Все карточки: `borderRadius: 16`, тень `shadow.s` или `shadow.none` + фоновый контраст
- [ ] Bottom sheet corners: `borderRadius: 24` (topLeft + topRight)
- [ ] Toggle: жёлтый `#FCE000` ON, серый `#D4D2CF` OFF (не зелёный!)
- [ ] Убрать все `w700/w900` из body текста — только `w400`
- [ ] Заголовки секций: Heading L (22px, w700)
- [ ] Горизонтальные margins всех страниц: строго `16px`
- [ ] Тени: убавить до `rgba(0,0,0,0.04-0.08)`, не более
