# Политика конфиденциальности «Курьер PRO Еда»

**Версия 1.0** • 05.10.2026

---

## Что собирает приложение

| Данные | Где хранятся | Куда передаются |
|--------|--------------|-----------------|
| **Имя, фамилия** (вводите сами) | Только на вашем телефоне | В Яндекс Еду — **только при нажатии «Заполнить анкету»** (реферальная ссылка) |
| **Телефон** (вводите сами) | Только на вашем телефоне | В Яндекс Еду — **только при нажатии «Заполнить анкету»** |
| **Страна, город, транспорт** (выбираете сами) | Только на вашем телефоне | В Яндекс Еду — вместе с вышеуказанными |
| **Тех. данные:** модель, ОС, язык, часовой пояс, ID установки | AppMetrica (Яндекс), Sentry | Анонимно — для аналитики и краш-репортов |
| **Действия в приложении** (экраны, нажатия, этапы) | AppMetrica (Яндекс) | Анонимно — для улучшения UX |

**Мы НЕ собираем:** GPS-геолокацию, контакты, SMS, фото, документы, банковские карты, пароли, историю заказов в Яндекс Еде.

---

## Как удалить ваши данные

- **Локальные данные (имя, телефон, настройки):** Профиль → «Очистить данные» или удалите приложение.
- **Аналитика / краш-логи:** Напишите на **privacy@kurier-pro-eda.ru** — удалим за 30 дней.

## Ответственность

**«Курьер PRO Еда» — информационный навигатор к партнёрской программе Яндекс Еды.**

- Мы **не нанимаем** курьеров, не выдаём сумки, не платим деньги, не настраиваем график.
- Все расчёты в калькуляторе — **прогнозы по публичным тарифам**. Реальный доход зависит от заказов, погоды, вашей активности.
- Чат-помощник — **ИИ (локальная база + GigaChat через шлюз)**. Ответы — рекомендации. По документам, штрафам, выплатам — в официальную поддержку Яндекс Еды.
