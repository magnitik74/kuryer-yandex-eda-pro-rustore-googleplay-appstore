# Мастер-Спецификация UI/UX: «Курьер PRO Еда» (v2.0 Senior Standard)

> **Назначение документа:** Абсолютный закон верстки, структуры экранов, логики взаимодействия и стор-комплаенса для приложения «Курьер PRO Еда».
> **Стандарт геометрии:** Сетка 16px, капсулы Pill (r=100), слои `#F6F5F3` / `#FFFFFF`, контрастный тёплый графит `#21201F`, брендовый жёлтый `#FCE000`.

---

## 🏛 1. Вход и Онбординг (Onboarding & Auth Flow)
* **Цель:** Максимальная конверсия в регистрацию без барьеров и 100% прохождение модерации сторов.
* **Экран 1: Splash** — Нативный мгновенный старт без таймеров задержки. Логотип «Курьер PRO Еда».
* **Экран 2: Онбординг (3 слайда-карусели)**:
  * Крупные заголовки 24px w700, подзаголовки 14px w400.
  * Плейсхолдеры под сочный 3D-визуал (авто, термокороб, монеты).
  * CTA-кнопка внизу: `h=52`, `r=100` (Pill), фон `#FCE000`, текст `#21201F` «Стать курьером».
* **Экран 3: Экран авторизации (Вход по номеру)**:
  * Поле ввода телефона: `h=52`, фон `#F6F5F3`, радиус `16px`.
  * Префикс `+7` с микро-разделителем и маска `(XXX) XXX-XX-XX`.
  * Поле ввода имени (1 строка).
  * **Zero-SMS принцип:** Любой корректный по маске номер сразу пускает внутрь. Для модераторов — мгновенный вход без ожидания SMS-кодов.

---

## 👤 2. Личный Кабинет (Dedicated Screen — Отдельный экран)
* **Точка входа:** Аватарка-капсула в правом верхнем углу Главного экрана (Header).
* **Анатомия экрана:**
  * **Карточка профиля (`bg=#FFFFFF`, `r=16`, тень `shadow.xs`):**
    * Аватар с инициалами пользователя на желтом фоне (`#FFFBE6`, бордер `#FCE000`).
    * Имя (Heading L 20px w700) и телефон с маской (Body M 14px `#6D6B69`).
    * **Статус аккаунта (Бейдж-таблетка `r=100`):** «Кандидат» (серый) / «Заявка отправлена» (желтый `#FFF9CC`) / «Курьер PRO» (зеленый `#00B341`).
  * **Секция «Мой транспорт»:** Выбранный тип (Авто / Пеший / Мото / Вело) с кнопкой быстрой смены.
  * **Секция настроек (`r=16`, фон `#FFFFFF`):**
    * Переключатель Push-уведомлений (Toggle: активный `#FCE000`, выкл `#D4D2CF`).
    * Смена языка (RU / UZ / TJ / KY).
    * Правовая информация и Оферта.
  * **Опасная зона (Apple / Google Compliance):**
    * Кнопка внизу: `Удалить аккаунт и персональные данные` (Цвет `#F5222D`, 14px w500).
    * По тапу — нативный системный BottomSheet / Dialog с предупреждением и подтверждением. При удалении локальная сессия очищается и приложение возвращается на онбординг.

## 🚏 3. Главный Экран (Hub — Выбор роли без города)
* **Никакого выбора города.** Выбор города только усложняет воронку и снижает конверсию.
* **Шапка экрана:**
  * Слева: «Привет, [Имя] 👋» (22px w700) + статус готовности к заказам.
  * Справа: Аватарка входа в Личный Кабинет.
* **Сетка 2×2 категорий доставки:**
  * 1. 🚗 **Автокурьер** (доход до 180 000 ₽ / мес)
  * 2. 🚶‍♂️ **Пеший курьер** (свободный график, легкий старт)
  * 3. 🛵 **Мотокурьер** (быстрые заказы без пробок)
  * 4. 🚲 **Велокурьер** (спорт + повышенный тариф)
* **Анатомия карточки:**
  * Фон `#FFFFFF`, скругление `16px`, внутренний отступ `16px`.
  * Иконка в скругленном квадрате `44×44px` (`r=12`, фон `#FFFBE6`).
  * Название роли (15px w600 `#21201F`) + бейдж дохода внизу.
* **Логика клика (Анти-роботизация):**
  * Тап по карточке **НЕ кидает в чат с готовым текстом**.
  * Открывается плавный BottomSheet (`r=24`):
    * «Вы выбрали: Автокурьер. Персональный помощник готов помочь с оформлением документов за 3 минуты.»
    * Кнопка `Pill h=52` «Перейти к диалогу с помощником».

## 💬 4. Персональный Помощник (Smart Registration Assistant)
* **Атмосфера:** Дорогой консьерж-сервис, а не глупый бот с заготовленными шаблонами.
* **Фон чата:** `#F6F5F3`.
* **Вход в диалог:**
  * Поле ввода снизу **абсолютно чистое**.
  * Помощник *сам* инициирует контакт:
    * Появляется индикатор набора текста (`...` 3 пульсирующие серые точки в белом бабле, 700мс).
    * Первое сообщение: *«Привет, [Имя]! Вижу, ты хочешь подключиться как [Автокурьер]. У тебя уже есть автомобиль или требуется аренда со скидкой?»*
* **Баблы сообщений:**
  * Помощник: Белый `#FFFFFF`, `r=18px`, левый нижний угол `r=4px`.
  * Пользователь: Теплый золотистый `#FFF9CC`, `r=18px`, правый нижний угол `r=4px`.
* **Интерактивные чипсы (Quick Replies):**
  * Горизонтальная прокрутка над полем ввода: `[Свой авто]`, `[Нужна аренда]`, `[Сколько платят?]`, `[Какие документы?]`.
  * При клике — мгновенная реакция с легкой вибрацией `HapticFeedback.lightImpact()`.

---

## 🏆 5. Интерактивные Шаги («Мой путь» — Геймификация воронки)
* **Цель:** Довести кандидата от скачивания до первого реального заказа через игровой прогресс.
* **Шапка модуля:**
  * Прогресс-бар во всю ширину: «Ваш статус: Новичок (Шаг 2 из 5 выполнен)».
  * Полоса заполнения: высота 8px, фон `#EBEBEB`, активный градиент `#FCE000` -> `#FFC700`.
* **Вертикальный интерактивный таймлайн:**
  * **Шаг 1: Создание профиля**
    * Статус: `✓ Выполнено` (Зеленый бейдж `#00B341`, галочка).
  * **Шаг 2: Подача онлайн-заявки**
    * Статус: `В процессе` (Пульсирующая желтая точка `#FCE000`, кнопка «Заполнить анкету»).
  * **Шаг 3: Быстрый экспресс-инструктаж (3 минуты)**
    * Статус: `Заблокировано 🔒` (Серый, разблокируется по завершении Шага 2).
  * **Шаг 4: Получение термокороба и мерча**
    * Статус: `Заблокировано 🔒` (Инструкция, где забрать короб бесплатно).
  * **Шаг 5: Первый заказ + Приветственный бонус (+5000 ₽)**
    * Статус: `Финал 🎁` (Золотой кубок, цель всей воронки).
* **Механика взаимодействия:**
  * Тап по шагу раскрывает детальную карточку с подсказками помощника.
  * Тактильный отклик при открытии шагов (`HapticFeedback.selectionClick()`).

## 💰 6. Калькулятор Дохода (Income Calculator)
* **Переключатель категории:** Капсульный Segmented Control (`#EBEBEB`, белая активная плашка с тенью).
* **Hero-цена:** Огромная цифра дохода (Display 34px Bold, `#21201F`), плавно анимирующаяся при движении слайдеров (эффект одометра/счетчика).
* **Слайдеры:**
  * 1. Слайдер «Дней в неделю» (от 1 до 7).
  * 2. Слайдер «Часов в день» (от 2 до 12).
  * Кастомная широкая дорожка `8px` (`#FCE000` / `#EBEBEB`), бегунок `28px` с окантовкой.
  * **Haptic:** Тиканье вибрации на каждое целое деление.
* **Нижний блок:**
  * Плашка «Выплаты ежедневно на любую карту» (`bg=#FFFBE6`, иконка щита).
  * CTA-кнопка: `h=52`, `r=100`, «Начать зарабатывать столько».
