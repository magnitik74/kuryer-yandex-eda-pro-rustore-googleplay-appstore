# Project Plan: fast_courier_app CPA Optimization & Growth Roadmap

1. Perform deep code exploration of screens: `MainScreen`, `PrelandingScreen`, `IncomeCalculatorTab`, `FaqTabContent`, `ChatTabContent` to detect CTA placements, conversion friction points, navigation flows, and UI styling.
